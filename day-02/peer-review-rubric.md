# Peer Review Rubric — API Spec Exercise

**Instructions**: Swap API specs with your partner. Review their work using this rubric.

---

## Review Checklist

### Completeness (Is everything there?)
- [ ] Endpoint clearly defined (method + URL)
- [ ] All query parameters documented
- [ ] Success response with example JSON
- [ ] Error responses with status codes
- [ ] Edge cases addressed (empty query, special chars, long query)
- [ ] Pagination explained
- [ ] Performance considerations noted

### Quality (Is it good?)
- [ ] A developer could implement this without asking questions
- [ ] Response format is consistent and predictable
- [ ] Error messages are helpful (not just "Bad Request")
- [ ] Edge cases are realistic (not contrived)

### Prompt Strategy (How did they work with Claude?)
- [ ] Evidence of iteration (spec improved over multiple rounds)
- [ ] Candidate thought of things Claude didn't suggest
- [ ] Candidate verified/questioned Claude's suggestions
