# Bug Hunting Exercise — E-Commerce Checkout

## The Application
A checkout flow for "ShopEasy" e-commerce. Run it and find the bugs.

## How to Run
```bash
pip install flask
python checkout_app.py
```
Open: `http://localhost:5002`

## Your Task
1. Test the checkout flow systematically
2. Find and document bugs (there are 8 deliberate ones)
3. Use the Bug Report Template for each bug
4. Classify severity: Critical / Major / Minor

## Checkout Flow
1. View cart → 2. Apply discount → 3. Enter shipping → 4. Review order → 5. Confirm
