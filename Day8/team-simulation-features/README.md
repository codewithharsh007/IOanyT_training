# Orchestrated Team Simulation

## Instructions

Teams of 4. Each person takes a role:
- **PM**: Creates project plan (15 min)
- **BA**: Writes requirements from PM's plan (15 min)
- **Engineer**: Implements from BA's requirements using Claude Code (45 min)
- **QA**: Tests engineer's output (30 min)
- **All**: Provide feedback to each other (15 min)

Then **ROTATE** roles and do Feature 2.

## Features

- **Feature 1**: `feature-1-todo-api.md` — Build a Todo list API
- **Feature 2**: `feature-2-weather-dashboard.md` — Build a weather data aggregator

## Handoff Protocol
At each handoff, the previous role must provide a clear written document that the next role can use independently. No verbal-only handoffs.
