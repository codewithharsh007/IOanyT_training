# Full Microservice Review — Scored Assessment

## Time: 2.5 hours

## What You're Reviewing
A complete REST API for a "BookShelf" personal library manager. ~300 lines across 4 files.

## Your Task (4 Phases)

### Phase 1: Systematic Review (60 min)
Read ALL files. Use the 5-dimension Code Review Framework.
Document every issue you find.

### Phase 2: Issue Documentation (30 min)
Organize your findings using `review-template.md`.
Classify each issue by severity (Critical / Major / Minor).

### Phase 3: Fix the Top 3 (30 min)
Write prompts for Claude to fix the 3 most important issues.

### Phase 4: Verify Fixes (30 min)
Check Claude's fixes. Did they actually solve the problem? Did they introduce new issues?

## Deliverables
Push to your branch:
1. `review-findings.md` — your completed review
2. Fixed code files
3. `verification-notes.md` — did the fixes work?
